# Bolo — બોલો

Learn the Gujarati your family speaks: short daily lessons, lots of speaking practice, family role-plays, a Home Gujarati phrasebook in three registers, and a Gujarati script course.

**Open the app:** https://harshvpatel09-alt.github.io/bolo-gujarati/ (use Chrome for speaking practice)

Audio is pre-recorded with a Hindi voice reading the Gujarati (the scripts map letter for letter) — close to native, but not a native Gujarati speaker.
